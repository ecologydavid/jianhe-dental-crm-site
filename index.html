如何將本系統完整映射到 Notion 中？

依據《Dental Practice - Run Your Clinic (Lite)》針對【或心設計有限公司 · 個案管理體系統】專屬優化的 5 大 Notion 關聯資料庫架構：

1. 📁 個案病患總表 (Patients Database)
  • 病患姓名 (Title)、病歷號 (Text)
  • 意向等級 (Select)：🔥高意向 / ⏳評估中 / ❄️觀望中 / ✅已成交 / ❌未成交
  • 全身健康警示 (Multi-select)：骨質疏鬆抗骨吸收藥物 / 高血壓 / 糖尿病 / 凝血異常 / 藥物過敏
  • 負責醫師 (Select)、負責個管師 (Person / Select)
  • 關聯 (Relation)：關聯至【約診排程庫】、【療程專案庫】、【技工工件庫】
2. 📅 約診排程日曆資料庫 (Appointments Database)
  • 約診主旨 (Title)：例如「示範病患 貼片試戴與黏固」
  • 約診時間 (Date 含時間)、約診時長 (Number 分鐘)
  • 看診醫師 (Select)：TE 醫師 / 銘 醫師 / 欣 醫師 / 彤 醫師 / 菀 醫師 / 海 醫師 / 葆 醫師 / 宇 醫師 / 葉 醫師 / 琪 醫師
  • 診間椅位 (Select)：A診 / B診 / C診
  • 約診狀態 (Select)：已預約 / 已報到 / 已完成 / 改期 / 未到
